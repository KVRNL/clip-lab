# Clip Lab

**Cut clips out of long stream recordings, instantly - by [KVRNL](https://kvrnl.io).**

Point Clip Lab at a recording (OBS or anywhere), scrub to the moment, mark a Start and End,
name it, and queue up as many clips as you want - then export them all at once. Bundled ffmpeg
means no setup, and even a 6-hour file opens instantly.

### Features
- Instant, lossless cuts (stream copy) - or frame-perfect re-encodes when you need exact edges
- Frame-perfect export uses your GPU (NVIDIA NVENC) with an automatic CPU fallback
- Queue up many clips and batch-export in one go
- Run several copies at once, one per video, without conflicts
- Built-in player with 15-second arrow-key seeking
